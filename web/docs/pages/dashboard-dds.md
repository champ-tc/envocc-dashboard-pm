# Dashboard DDS — `/dashboard/dds`

## กติกาก่อนแก้ไข

ต้องอ่านไฟล์นี้, `web/src/app/dashboard/dds/README.md` และ `web/AGENTS.md` ก่อนแก้ `web/src/app/dashboard/dds/` ทุกครั้ง หากเปลี่ยน behavior หรือ visual contract ต้องอัปเดตเอกสารทั้งสองไฟล์ใน change เดียวกัน

## DDS contract และการอนุญาตแก้ไข

เอกสารนี้เป็น checklist บังคับสำหรับการแก้หน้า DDS โดย AI หรือผู้พัฒนา:

- ต้องอ่าน `web/src/app/dashboard/dds/README.md`, implementation และ test ก่อนแก้
- ต้องรักษา diagnosis rules, role scope, cascading filters, shared filter state, loading/error/empty state และผลลัพธ์ของ cards/กราฟ/แผนที่ให้สอดคล้องกัน
- การลบหรือเปลี่ยนเงื่อนไขเดิม, รหัส ICD-10, mapping, fallback หรือการนับ ต้องมีคำสั่งผู้ใช้โดยตรง; ถ้าไม่มีคำสั่งให้คง behavior เดิม
- เมื่อได้รับอนุญาตให้เปลี่ยน behavior ต้องบันทึกเหตุผลในเอกสารนี้/README, ปรับ test และตรวจ diff หลังแก้
- หากเอกสารกับโค้ดขัดแย้งกัน ให้หยุดเพื่อยืนยัน source of truth ก่อนลงมือ ไม่ให้ build/lint เป็นตัวตัดสิน behavior

### Diagnosis contract ที่ห้ามเปลี่ยนโดยปริยาย

- โหมด EnvOcc + `Z58.1`: `person_id` เดียวกันต้องมี `Z58.1` และรหัส EnvOcc อย่างน้อยหนึ่งรหัส
- โหมด EnvOcc + `Z58.1` + `Y97`: `person_id` เดียวกันต้องมีครบทั้งสามเงื่อนไข
- โหมด custom: ต้องมี `Z58.1` และนับเฉพาะรหัส/กลุ่มโรคที่ผู้ใช้เลือก
- โหมด EnvOcc ใช้เฉพาะชุดรหัสที่กำหนดใน `DISEASE_ICD_OPTIONS`/`DDS_DISEASES`; รหัสทั่วไปจาก `DiseaseGroup.json` ใช้กับโหมด custom เท่านั้น
- การนำ ICD-10 ออกจากการ์ดต้องนำออกจากผลลัพธ์ทุกส่วน และไม่ย้ายไปเพิ่มกลุ่มอื่นโดยอัตโนมัติ

## ตัวกรองและเงื่อนไข

- [ ] ช่วงวันที่เริ่มต้น/สิ้นสุด
- [ ] เขตสุขภาพและจังหวัด พร้อมการเลือกหลายรายการ/ค้นหาจังหวัด
- [ ] อำเภอ/พื้นที่ที่เกี่ยวข้อง (ถ้ามีใน options) ไม่ถูกตัดออก
- [ ] ประเภทการวินิจฉัยและโรค/รหัสโรคยังอยู่ รวม custom Z581
- [ ] ตัวกรอง DDS แยกจาก PM2.5/HDC และ serialize/restore ผ่าน URL

## ผลลัพธ์ที่ต้อง sync กับ filter

- [ ] แผนที่/ข้อมูลพื้นที่
- [ ] cards สรุปโรคและจำนวนผู้ป่วย
- [ ] กราฟแนวโน้มรายเดือน จำนวนผู้ป่วย และค่าเฉลี่ย PM2.5
- [ ] กราฟแนวโน้มรายเดือนแสดงครบทุกเดือนภายในช่วงวันที่ที่เลือก และเรียงตามเวลา
- [ ] เดือนที่ไม่มีรายการวินิจฉัยยังแสดงเป็นค่า 0; ป้ายเดือนยึดกึ่งกลางแท่ง และเมื่อเกิน 15 เดือนให้แสดงแนวตั้งพร้อมย่อขนาด โดยไม่ทับพื้นที่เส้น/แท่ง
- [ ] tooltip, legend และปุ่ม export กราฟ

## Shared map/background/EnvOcc rules

- [ ] ถ้ามีแผนที่ ต้องใช้ map component, boundary, สี, legend และ popup มาตรฐานเดียวกับ dashboard อื่น
- [ ] พื้นที่บนแผนที่ต้องตรงกับ filter DDS และข้อมูล cards/กราฟ ไม่ใช้ข้อมูลชุดเก่าหลังเปลี่ยน filter
- [ ] พื้นหลัง dashboard/visual layer ยังอยู่ครบและไม่บดบัง filter, map หรือ tooltip
- [ ] รหัสโรคและชื่อโรค EnvOcc ต้องคงตาม mapping ที่อ้างอิง พ.ร.บ.; ห้ามเปลี่ยน label เพื่อให้ตรงกับข้อมูลชั่วคราวโดยไม่มีการยืนยัน

## ตรวจรับ

- [ ] เปลี่ยน filter แล้วไม่มีข้อมูลจาก filter เดิมปะปน
- [ ] Refresh/Back/Forward/เปิด URL เดิมคืนค่าเดิม
- [ ] error/empty/loading ไม่ reset filter และยังมี retry
