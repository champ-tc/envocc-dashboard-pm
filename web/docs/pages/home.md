# หน้าหลัก `/`

## กติกาก่อนแก้ไข

ต้องอ่านไฟล์นี้และ `web/AGENTS.md` ก่อนแก้ `web/src/app/page.tsx` ทุกครั้ง หากเปลี่ยน behavior หรือ visual contract ต้องอัปเดตไฟล์นี้ใน change เดียวกัน

## สิ่งที่ต้องคงไว้

- [ ] `GuestNavbar` และลิงก์ไป Login/Register ทำงาน
- [ ] Hero และชื่อระบบ PM2.5 แสดงครบ
- [ ] คำนิยามทั้ง 6 รายการ รวมโรค, threshold 37.5/75 และแหล่งข้อมูล HDC/DDS/Air4Thai
- [ ] ลิงก์ภายนอกเปิดได้และไม่ทำให้หน้าเดิมหาย
- [ ] `OpenSkyBackground`, responsive layout และข้อความภาษาไทยยังอยู่
- [ ] ห้ามเปลี่ยน threshold หรือข้อความเชิงความหมายโดยไม่มีข้อกำหนดใหม่
- [ ] พื้นหลังและ visual identity ใช้ asset/component เดิมอย่างสม่ำเสมอ
- [ ] รายการโรค/อาการ EnvOcc และข้อความอ้างอิง พ.ร.บ. ต้องไม่ถูกลบหรือเปลี่ยนความหมาย

## ตรวจรับ

- [ ] เปิด `/` แล้วเห็นเนื้อหาครบโดยไม่ต้อง login
- [ ] ปุ่ม Login ไป `/login` และ Register ไป `/register`
- [ ] ตรวจ mobile/desktop และลิงก์ภายนอก
