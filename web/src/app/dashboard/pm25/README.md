# PM2.5 Dashboard — รายละเอียดหน้าจอ

> กติกาบังคับ: ต้องอ่านไฟล์นี้, `web/docs/pages/dashboard-pm25.md` และ `web/AGENTS.md` ก่อนแก้หน้า PM2.5 ทุกครั้ง และต้องอัปเดตเอกสารเมื่อ behavior หรือ visual contract เปลี่ยน

เอกสารนี้อธิบายหน้าจอ `/dashboard/pm25` ตาม `page.tsx` ปัจจุบัน ทั้งตัวกรอง ค่าที่สรุป แผนที่ กราฟ และธีมสี

## โครงสร้างและพื้นหลัง

- พื้นหลังเป็นภาพ `/img/background-optimized.jpg` แบบ fixed, cover, center, no-repeat และมี overlay `bg-slate-900/15`
- Header แสดงโลโก้ DDC ชื่อ “การเฝ้าระวังสถานการณ์ฝุ่นละอองขนาดไม่เกิน 2.5 ไมครอน (PM2.5) ประเทศไทย” และชื่อหน่วยงาน
- ส่วนเนื้อหาใช้ `max-w-screen-2xl`, `min-h-screen`, flex column และ gap 4
- แผงกราฟ/แผนที่ใช้ `bg-neutral-900/25`, `backdrop-blur-2xl`, `border-white/15`, `ring-white/10`, `shadow-2xl`, `rounded-3xl`

## ตัวกรอง

แผง filter เป็น grid 1 คอลัมน์บนมือถือ, 2 ที่ `sm`, 3 ที่ `md` และ 6 ที่ `xl`:

1. **จากวันที่ / ถึงวันที่** — เลือกเฉพาะวันที่ไม่เกินวันปัจจุบัน; ค่าเริ่มต้นถึงวันที่ล่าสุด และเริ่มตั้งแต่วันที่ 1 ตุลาคมของปีงบประมาณเดียวกัน
2. **เขตสุขภาพ** — multi-select
3. **จังหวัด** — multi-select ตามเขต
4. **อำเภอ/เขต** — multi-select ตามจังหวัด

การเปลี่ยนเขตจะสร้างรายการจังหวัดที่เกี่ยวข้องและล้างอำเภอ; การเปลี่ยนจังหวัดจะสร้างรายการอำเภอที่เกี่ยวข้อง ค่าที่เลือกทั้งหมดจะถูกตัดออกจาก query เพื่อให้ความหมายเท่ากับไม่จำกัดพื้นที่

## การ์ดสรุป 4 ใบ

- **ค่า PM2.5 เฉลี่ย 24 ชั่วโมง** — หน่วย `มคก./ลบ.ม.` การ์ดหลัก gradient `from-blue-600/90` → `to-sky-500/90`
- **ค่า PM2.5 เฉลี่ย 24 ชั่วโมงสูงสุด** — หน่วยเดียวกัน การ์ดเข้มโปร่งแสงและมี accent สี rose
- **จำนวนจังหวัดที่เกิน 37.5** — แสดงจำนวนจังหวัดและปุ่ม “ดูรายละเอียด” สีส้ม เปิด dialog รายจังหวัดแยกตามเขตสุขภาพ
- **จำนวนจังหวัดที่มากกว่า 75** — แสดงจำนวนจังหวัดและปุ่ม “ดูรายละเอียด” สีแดง เปิด dialog เช่นเดียวกัน

Dialog ใช้พื้น `base-100`, ขอบ `base-300`, เนื้อหาการ์ด `base-200/50`; ถ้าไม่พบข้อมูลจะแสดงข้อความว่างแทนรายการ

## Ranking และแผนที่

ด้านหลังการ์ดมีสองแถวแบบ 2 คอลัมน์บนจอใหญ่ และ 1 คอลัมน์บนมือถือ:

- **Top 10 พื้นที่ที่มีวันเกินมาตรฐานมากที่สุด** — ranking แสดงจำนวนวันและระดับพื้นที่ที่คำนวณได้: province, district หรือ subdistrict
- **แผนที่ PM2.5 เฉลี่ย 24 ชั่วโมงสูงสุด** — ใช้ค่าสูงสุดในช่วงวันที่เลือก
- **แผนที่จำนวนวันต่อเนื่อง >37.5** — สี/ค่าเป็นจำนวนวันที่เกิน 37.5 ติดต่อกันล่าสุด ณ วันสิ้นสุดที่เลือก
- **แผนที่จำนวนวันต่อเนื่อง >75** — ค้นหาเหตุการณ์ล่าสุดที่เกิน 75 ติดต่อกันตั้งแต่ 2 วันขึ้นไป

แผนที่ปรับระดับพื้นที่อัตโนมัติ: ไม่เลือกจังหวัดแสดงจังหวัด, เลือกจังหวัดแสดงอำเภอ, เลือกอำเภอแสดงตำบล โดยจับคู่จังหวัด/อำเภอ/ตำบลให้ตรงกันและซ่อนพื้นที่ที่ไม่มีข้อมูล

### สีและ legend ของแผนที่

แผนที่ค่า PM2.5 ใช้ 5 ระดับ: 0–15 ฟ้า `#0ea5e9` (ดีมาก), 15–25 เขียว `#10b981` (ดี), 25–37.5 เหลือง `#eab308` (ปานกลาง), 37.5–75 ส้ม `#f97316` (เริ่มมีผลกระทบ), และ 75+ ชมพูแดง `#f43f5e` (มีผลกระทบ)

แผนที่ streak 37.5 ใช้โทนส้ม 1–3 วัน, 4–7 วัน, 8–14 วัน และ 15+ วัน; แผนที่ streak 75 ใช้พื้นโปร่งแสงสำหรับน้อยกว่า 2 วัน และแดง `#ef4444` สำหรับ 2 วันขึ้นไป

Popup แสดงชื่อพื้นที่ ค่า/จำนวนวัน หน่วย และช่วงวันที่ของ streak เมื่อมีข้อมูล

## กราฟเส้นแนวโน้ม

มีกราฟเต็มความกว้าง 3 รายการ โหลดแบบ deferred เมื่อเลื่อนเข้าใกล้:

- ค่าเฉลี่ย 24 ชั่วโมงรายเขตสุขภาพ
- ค่าเฉลี่ย 24 ชั่วโมงรายจังหวัด
- ค่าเฉลี่ย 24 ชั่วโมงรายอำเภอ/เขต

แต่ละกราฟเป็น multi-line chart; เส้นใช้ palette แบบวนซ้ำ `#3b82f6`, `#ef4444`, `#10b981`, `#f59e0b`, `#8b5cf6`, `#ec4899`, `#06b6d4`, `#14b8a6`, `#f43f5e`, `#6366f1` มีจุด marker, legend และ tooltip แสดงชื่อพื้นที่ วันที่ และค่า PM2.5

## Responsive และการส่งออก

- แผนที่/Ranking สูงประมาณ 560px บนจอทั่วไป และ 640px บน `lg`
- กราฟแต่ละรายการสูงประมาณ 29.375rem
- มีปุ่ม export ภาพในกรอบแผนที่และกราฟ
- footer ถูกซ่อน; scrollbar หลักมี track `rgba(255,255,255,0.05)` และ thumb `rgba(255,255,255,0.2)`
