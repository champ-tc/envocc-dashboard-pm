# DDS Dashboard — รายละเอียดหน้าจอ

เอกสารนี้อธิบายสิ่งที่ผู้ใช้เห็นและพฤติกรรมของหน้า `/dashboard/dds` ตาม `page.tsx` ปัจจุบัน โดยข้อมูลวิเคราะห์มาจาก Server Actions และไฟล์ข้อมูลที่แชร์จาก Airflow ไม่ควรแก้ไฟล์ผลลัพธ์ใน runtime โดยตรง

## ภาพรวมหน้าจอ

- พื้นหลังเป็นภาพท้องฟ้าเปิด ใช้แบบเต็มหน้าจอ และมี overlay โปร่งแสงเพื่อให้อ่านข้อความสีขาวได้
- ส่วนหัวแสดงโลโก้ DDC และ DOE ชื่อระบบเฝ้าระวัง PM2.5/โรคที่เกี่ยวข้อง และ subtitle ตามสิทธิ์ผู้ใช้
- มี busy/loading overlay ระหว่างเปลี่ยนตัวกรองหรือโหลดข้อมูล
- ส่วนใหญ่ใช้แผง Glassmorphism พื้นเข้มโปร่งแสง `bg-neutral-900/25`, `backdrop-blur-2xl`, ขอบ `border-white/15`, เงาเข้ม และมุมโค้ง `rounded-3xl`

## ตัวกรอง

แผงตัวกรองเป็น grid 1 คอลัมน์บนมือถือ, 2 คอลัมน์ที่ `sm`, 3 คอลัมน์ที่ `md` และ 7 คอลัมน์ที่ `xl` ประกอบด้วย:

1. **จากเดือน / ถึงเดือน** — date picker แบบเลือกปี พ.ศ. และเดือน โดยค่าเริ่มต้นถึงเดือนล่าสุด และเริ่มจากเดือนตุลาคมของปีงบประมาณเดียวกัน
2. **เขตสุขภาพ** — searchable single-select; ค่าเริ่มต้น “ทั้งหมด”
3. **จังหวัด** — แสดงจังหวัดตามเขตที่เลือกและค้นหาได้
4. **อำเภอ/เขต** — เปิดใช้งานเมื่อเลือกจังหวัด
5. **ตำบล/แขวง** — เปิดใช้งานเมื่อเลือกอำเภอ
6. **ประเภทวินิจฉัย** — single-select จากรายการในข้อมูล เช่น พ.ร.บ. EnvOcc ร่วมกับ Z58.1, แบบเพิ่ม Y97 และแบบกำหนดกลุ่มโรคเอง

การเลือกพื้นที่เป็น cascading: เปลี่ยนเขตจะล้างจังหวัด/อำเภอ/ตำบล, เปลี่ยนจังหวัดจะล้างอำเภอ/ตำบล และเปลี่ยนอำเภอจะล้างตำบล ตัวกรองระดับพื้นที่เป็น single-select ต่างจากตัวเลือก ICD-10 ในการ์ดโรคที่เลือกได้หลายรหัส

### เงื่อนไขประเภทวินิจฉัย

ระบบตรวจสอบเงื่อนไขในระดับ `person_id` ภายในช่วงเวลาและพื้นที่ที่เลือก:

- **การวินิจฉัยโรคตาม พ.ร.บ. EnvOcc ร่วมกับ Z58.1** — คนเดียวกันต้องมี `Z58.1` และมีรหัสตาม พ.ร.บ. อย่างน้อย 1 รหัส หากมี `Z58.1` เพียงอย่างเดียวจะไม่ถูกนับ
- **การวินิจฉัยโรคตาม พ.ร.บ. EnvOcc ร่วมกับ Z58.1+Y97** — คนเดียวกันต้องมีครบ `Z58.1`, `Y97` และรหัสตาม พ.ร.บ. อย่างน้อย 1 รหัส หากขาดรายการใดรายการหนึ่งจะไม่ถูกนับ
- **การวินิจฉัย Z58.1 ร่วมกับกลุ่มโรคที่ต้องการ** — คนเดียวกันต้องมี `Z58.1` และระบบจะแสดงเฉพาะรหัส/กลุ่มโรคที่ผู้ใช้เลือก

สองโหมด พ.ร.บ. ใช้เฉพาะชุดรหัส EnvOcc ที่กำหนดใน `DISEASE_ICD_OPTIONS`/`DDS_DISEASES`; รหัสทั่วไปที่อยู่ใน `DiseaseGroup.json` แต่ไม่อยู่ในชุด พ.ร.บ. จะไม่ถูกแสดงหรือถูกนับในสองโหมดนี้ รหัสจาก `DiseaseGroup.json` ทั้งหมดใช้ได้เฉพาะโหมดกำหนดกลุ่มโรคเอง

การยกเลิกรหัส ICD-10 จากการ์ดจะตัดรหัสดังกล่าวออกจากข้อมูลทุกส่วน ไม่ย้ายไปเพิ่มในกลุ่มโรคอื่น

## ค่าสรุปและการ์ดโรค

- **จำนวนผู้ป่วยการวินิจฉัยโรคทั้งหมด** — จำนวน `person_id` แบบไม่ซ้ำ หน่วย “ราย” พื้นหลัง gradient น้ำเงิน `from-blue-600/90` ไป `to-sky-500/90`
- **จำนวนการวินิจฉัยทั้งหมด** — จำนวนรายการ/ครั้งที่ตรงกับตัวกรอง พื้นหลังเข้มโปร่งแสง
- การ์ดกลุ่มโรค 5 ใบ: โรคระบบทางเดินหายใจ, โรคระบบไหลเวียนเลือด, โรคผิวหนังและเนื้อเยื่อใต้ผิวหนัง, โรคตาและส่วนประกอบของตา และกลุ่มอื่นๆ/สถานะสุขภาพ โดยตัวเลขเป็น “รายการวินิจฉัย” และผลรวมของการ์ดตรงกับจำนวนการวินิจฉัยทั้งหมด
- การ์ดโรคมีตัวเลขจำนวน “รายการวินิจฉัย” และ multi-select รหัส ICD-10; แบบ custom Z58.1 จะแสดงการจัดกลุ่มรหัสและค้นหารหัสได้
- จำนวนผู้ป่วยทั้งหมดนับคนไม่ซ้ำ ส่วนจำนวนการวินิจฉัยและตัวเลขบนการ์ดกลุ่มโรคนับเป็นรายการ ดังนั้นผลรวมการ์ดกลุ่มโรคจะตรงกับจำนวนการวินิจฉัยทั้งหมด แต่ไม่จำเป็นต้องตรงกับจำนวนผู้ป่วยทั้งหมด
- สี accent ของกลุ่มโรคที่ใช้ในกราฟคือ rose, orange, emerald, blue และ purple ตามลำดับ

## กราฟแนวโน้มรายเดือน

- แผงกราฟอยู่ด้านซ้ายของแผนที่บนจอใหญ่ และเรียงเต็มความกว้างบนจอเล็ก
- แท่งซ้อนแสดงจำนวนการวินิจฉัยรายเดือน แยกสีตามกลุ่มโรค โดยนับเป็นรายการวินิจฉัยให้สอดคล้องกับการ์ดสรุป
- เส้นสี rose `#f43f5e` แสดงค่าเฉลี่ย PM2.5 รายเดือน ใช้แกนขวาแยกจากจำนวนผู้ป่วย
- แกนซ้ายเป็น “จำนวนการวินิจฉัย (ครั้ง)” และแกนขวาเป็น “ค่าเฉลี่ยฝุ่น PM2.5 (มคก./ลบ.ม.)” พร้อมเส้น grid สีขาวโปร่งแสง
- Hover จุด/แท่งจะแสดงเดือน ค่า PM2.5 จำนวนการวินิจฉัยแยกกลุ่ม และการวินิจฉัยรวม
- มี legend สีของกลุ่มโรคและเส้น PM2.5 พร้อมปุ่ม export ภาพกราฟ

## แผนที่

- แสดงจำนวนผู้ป่วยไม่ซ้ำบน Thailand Map และมีปุ่ม export ภาพ
- ไม่เลือกพื้นที่: แสดงรายจังหวัด/ภูมิภาค; เลือกจังหวัดจะแสดงรายอำเภอ; เลือกอำเภอจะแสดงรายตำบล
- สีแผนที่ 5 ระดับ: 0–10, 11–50, 51–100, 101–200 และ 201 รายขึ้นไป; ในมุมมองละเอียดใช้คำว่า น้อยมาก → สูงมาก
- Popup แสดงชื่อพื้นที่ จำนวนผู้ป่วย และรายละเอียดตามระดับมุมมอง
- ตัวแผนที่อยู่ในกรอบเข้ม `bg-neutral-900/25` และพื้นที่แผนที่ใช้พื้น `bg-slate-800/50`, ขอบบางสีขาว และเงาด้านใน

## สิทธิ์และความถูกต้องของข้อมูล

- `admin_province` ถูกบังคับให้เห็นเฉพาะจังหวัดของตนเองทั้งรายการตัวกรองและผลลัพธ์
- `admin_region` ถูกบังคับให้เห็นเฉพาะเขตสุขภาพของตนเองทั้งรายการตัวกรองและผลลัพธ์
- การเปลี่ยน filter จะใช้ชุดข้อมูลเดียวกันสำหรับ KPI, การ์ด, กราฟ และแผนที่
- ค่า PM2.5 เฉลี่ยคำนวณจากข้อมูล PM2.5 โดยตรงตามช่วงเวลาและพื้นที่ ไม่ถูกถ่วงน้ำหนักด้วยจำนวนรายการวินิจฉัย

## Responsive และสถานะพิเศษ

- เดสก์ท็อปใช้ layout กราฟ/แผนที่สองคอลัมน์; มือถือเรียงเป็นแนวตั้ง
- loading ใช้ skeleton และทำให้ main content ไม่รับ interaction ชั่วคราว
- dropdown ใช้พื้น `bg-slate-900/95`, blur, ขอบบาง และ scrollbar แบบซ่อน
- footer ถูกซ่อน และ scrollbar หลักมีขนาดเล็ก พื้น/หัว scrollbar เป็นสีขาวโปร่งแสง
