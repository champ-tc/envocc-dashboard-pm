# HDC Dashboard — รายละเอียดหน้าจอ

> กติกาบังคับ: ต้องอ่านไฟล์นี้, `web/docs/pages/dashboard-hdc.md` และ `web/AGENTS.md` ก่อนแก้หน้า HDC ทุกครั้ง และต้องอัปเดตเอกสารเมื่อ behavior หรือ visual contract เปลี่ยน

เอกสารนี้อธิบายหน้าจอ `/dashboard/hdc` ตาม implementation ปัจจุบัน

## ภาพรวมและพื้นหลัง

- ใช้ภาพพื้นหลังท้องฟ้าแบบเต็มหน้าจอจาก `OpenSkyBackground` พร้อม overlay โปร่งแสง
- Header แสดงโลโก้ DDC ชื่อระบบ PM2.5 และ subtitle ของหน่วยงาน/บทบาทผู้ใช้
- แผงทั้งหมดใช้ธีมเข้มแบบ glass: `bg-neutral-900/25`, `backdrop-blur-2xl`, `border-white/15`, `ring-white/10`, `shadow-2xl`, `rounded-3xl`
- ระหว่างโหลดข้อมูลมี loading overlay และ main ถูกทำให้ไม่รับ interaction

## ตัวกรอง

แผงตัวกรองจัดเป็น 1 คอลัมน์บนมือถือ, 2 ที่ `sm`, 3 ที่ `md` และ 6 ที่ `xl` ได้แก่:

- **จากเดือน / ถึงเดือน** — เลือกจากเดือนที่มีใน Parquet; ค่าเริ่มต้นถึงเดือนล่าสุดและเริ่มที่เดือนตุลาคมของปีงบประมาณเดียวกัน
- **เขตสุขภาพ** — multi-select
- **จังหวัด** — multi-select ตามเขตที่เลือก
- **อำเภอ/เขต** — multi-select ตามจังหวัดที่เลือก ใช้กำหนดพื้นที่ของข้อมูล/การแสดงผล
- **กลุ่มโรค** — multi-select จากรายการโรค HDC
- **ประเภทวินิจฉัย** — single-select เช่น โรคหลักหรือโรคร่วมกับ Z58.1

ความสัมพันธ์พื้นที่เป็น cascading: เขต → จังหวัด → อำเภอ/เขต; เปลี่ยนระดับบนจะล้างค่าระดับล่างที่ไม่เกี่ยวข้อง จังหวัดค้นหาได้ และตัวเลือก “ทั้งหมด” ใช้แทนการส่งรายการทั้งหมดไป query

สิทธิ์ `admin_region` และ `admin_province` จำกัดพื้นที่ที่เลือก/มองเห็นตาม scope ของผู้ใช้

## การ์ดสรุป

- การ์ดหลักแสดง **จำนวนการวินิจฉัยทั้งหมด** หน่วย “ครั้ง” ด้วย gradient น้ำเงิน/ฟ้า
- การ์ดรอง 5 ใบแสดงจำนวนผู้ป่วยตามกลุ่มโรค HDC แต่ละใบมีสี accent และจุด/แถบสีประจำโรค
- การ์ดเรียง 2 คอลัมน์บนมือถือขนาดเล็ก, 3 ที่ `sm` และ 5 ที่ `xl`

## กราฟแนวโน้มรายเดือน

- แสดงแท่งซ้อนจำนวนผู้ป่วยแยกตามกลุ่มโรค และเส้นค่าเฉลี่ย PM2.5 รายเดือนบนแกนคู่
- แกนซ้ายเป็นจำนวนผู้ป่วย แกนขวาเป็นค่า PM2.5; ค่าสูงสุดของแกนคำนวณจากข้อมูลและเผื่อขอบบนประมาณ 10%
- สีเส้น/แท่งใช้ mapping สีของ `HDC_DISEASES`; tooltip เมื่อ hover แสดงเดือน ค่า PM2.5 และรายละเอียดกลุ่มโรค
- มี legend สีโรค, ป้ายเดือนภาษาไทย และปุ่ม export ภาพกราฟ

## แผนที่จำนวนผู้ป่วย

- แผนที่อยู่ด้านขวาของกราฟบนจอใหญ่ และเรียงต่อด้านล่างบนมือถือ
- แสดงจำนวนผู้ป่วยรายจังหวัด พร้อมอัตราป่วยต่อแสนประชากรจากประชากรกลางปีใน `mid_year.csv`
- สี 5 ระดับ: 0–10, 11–50, 51–100, 101–200 และ 201 รายขึ้นไป
- จังหวัดที่ไม่มีข้อมูลไม่ลงสี แต่ยังแสดงเส้นขอบเขต; ค่าศูนย์ที่มีข้อมูลอยู่ในช่วงต่ำสุด
- เมื่อกรองเขต/จังหวัดจะปรับพื้นที่ที่มองเห็นให้สอดคล้องกับ filter; แผนที่ปิดการลากและซูมเพื่อคงมุมมองรายงาน
- Popup แสดงชื่อจังหวัด, จำนวนผู้ป่วย และอัตราป่วย “ต่อแสน”; มี legend และปุ่ม export

## Responsive และ visual details

- layout หลักเป็นกราฟ 1.6fr ต่อแผนที่ 1.1fr บนจอใหญ่
- dropdown อยู่เหนือ layer อื่นด้วย z-index สูง เพื่อไม่ให้ tooltip/การ์ดบัง
- พื้นที่แผนที่ใช้พื้น `bg-slate-800/50` และขอบสีขาวโปร่งแสง
- ซ่อน footer และใช้ scrollbar ขนาดเล็กที่มี track/thumb สีขาวโปร่งแสง
