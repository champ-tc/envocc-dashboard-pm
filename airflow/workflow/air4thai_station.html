Technical Deep Dive: Station Sync

เจาะลึกการทำงานของระบบซิงค์ข้อมูลสถานีตรวจวัดคุณภาพอากาศ (Master Data Management)

ข้อมูลและตัวแปรที่เกี่ยวข้อง (Variables & Secrets)

1. Airflow Variables

KeyDescriptionUsage
air4thai_station Discord Webhook URL ใช้ในการส่งข้อความแจ้งเตือนผลการซิงค์ข้อมูลเข้าห้อง Discord

2. Environment Variables

ตัวแปรเหล่านี้ต้องถูกตั้งค่าในระบบ (เช่น ใน Docker หรือ Airflow Connection) เพื่อใช้ในการเชื่อมต่อฐานข้อมูล:

Variable NameDescription
DB_USER / DB_PASSWORDUser และ Password สำหรับเข้าใช้งาน PostgreSQL
DB_HOST / DB_PORTที่อยู่ของ Database Server และ Port (Default: 5432)
DB_NAMEชื่อฐานข้อมูลเป้าหมาย
PROVINCE_XLSX_PATHตำแหน่งไฟล์ resources/Province.xlsx สำหรับ Map เขตสุขภาพ

รายละเอียดขั้นตอน (Detailed Tasks)

1. check_db

รันฟังก์ชันจาก check_db/check_db.py เพื่อทดสอบการ Ping ฐานข้อมูล

2. sync_stations

รันสคริปต์ stations/stations.py:

  • ดึง JSON จาก Air4Thai
  • Normalize ชื่อจังหวัด (เช่น กาฬสิน -> กาฬสินธุ์)
  • Map health_region จากไฟล์ Excel
  • เปรียบเทียบข้อมูลเดิมในตาราง stations
  • ส่งค่า inserted_count และ updated_count ผ่าน XCom

3. notify_station_changes

ดึงค่าจาก XCom มาตรวจสอบ:

  • ถ้ามีการเปลี่ยนแปลง -> เรียกใช้ฟังก์ชันกลาง notify/discord_notify.py เพื่อส่งข้อความ
  • ถ้าไม่มีการเปลี่ยนแปลง -> Skip การส่งข้อความ

ข้อมูลเพิ่มเติม

ตาราง stations มีการใช้ Index ในคอลัมน์ station_id และ station_id_new เพื่อประสิทธิภาพในการค้นหาและเปรียบเทียบข้อมูลที่รวดเร็ว
